# 代購營運後台系統 (Global Proxy Buy Ops) 實作計畫

為專業跨國代購團隊（日本、韓國、歐美精品與潮流連線）量身打造的高效能營運後台，提供從商品報價開單、多國採購清單彙總、二階段訂金與尾款對帳核銷，到分包出貨與顧客管理的一站式作業平台。

---

### User Review & Critical Decisions

> [!IMPORTANT]
> 依據前期需求確認，本系統採用以下關鍵決策：

- **已確認決策 1：多國市場與即時匯率設定**
  預設支援日幣 (JPY)、韓元 (KRW)、美金 (USD)、歐元 (EUR) 與新台幣 (TWD) 基準換算。支援自訂匯率加成（Buffer 匯率，如日幣即時 0.21，代購設定 0.225 以規避匯差波動）。
- **已確認決策 2：自動智慧定價公式**
  開單管理支援公式化計價：`售價 = (原幣成本 × 設定匯率) + 服務費 (固定費或 % 比例) + 預估國際空海運費`，並保留業務人員手動優惠微調或抹零功能。
- **已確認決策 3：二階段收款對帳機制**
  嚴格落實兩段式款項追蹤：
  1. **第一階段（訂金 / 商品款）**：顧客委託確認後產生訂金單，待款項（末五碼或截圖憑證）核銷後，訂單轉入「待採購」。
  2. **第二階段（尾款 / 國際運費與關稅）**：商品抵達台灣倉過秤並量測體積重後，系統產出尾款與國內宅配帳單，核銷完成後放行出貨。

### 1. Overview & Core Concept

- **目標使用者**：日韓連線代購主、歐美精品買手、團購主及助理小幫手。
- **核心價值**：
  - 徹底告別混亂的 LINE 訊息記帳與 Excel 跑單漏單困擾。
  - 將「報價開單 ➔ 訂金對帳 ➔ 跨店/官網採購彙總 ➔ 物流抵台秤重 ➔ 尾款結清 ➔ 發貨」流暢串聯。
  - 提供即時毛利分析、各國幣別資金水位與待辦催款預警。

### 2. User Experience & Visual Design

#### A. 核心模組與操作流程

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│ 1. 開單報價 │ ─> │ 2. 訂金對帳 │ ─> │ 3. 採購彙總 │ ─> │ 4. 到貨秤重 │ ─> │ 5. 尾款發貨 │
│ 快速貼圖/網址│    │ 末5碼核銷確認│    │ 跨訂單同品彙整│    │ 實重分攤與尾款│    │ 出貨單與完結│
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
```

1. **營運總覽 (Dashboard)**
   - 核心營運指標卡（本月累計委託金額、代購淨毛利、待核銷對帳筆數、待採購品項數、待付尾款總額）。
   - 代購國家佔比分佈（日本 JPY、韓國 KRW、美國/歐洲精品）。
   - 待辦事項與即時預警清單（如：逾 48 小時未付訂金、採購缺貨預警、抵台待秤重提醒）。
2. **開單管理 (Quote & Order Intake)**
   - 快速開單抽屜/表單：輸入商品原幣、類別、購入來源（官網/專櫃/連線現場）、客戶資訊、件數、預估重量。
   - 自動試算建議售價與預收訂金（支援 50% 訂金或全額商品款）。
   - 一鍵複製顧客友善的格式化報價文字（含匯款帳號、匯率明細、注意事項），方便直接貼到 LINE / IG 私訊。
3. **訂單管理 (Order Lifecycle)**
   - 狀態管道流水：`詢價待付訂` ➔ `已付訂待採購` ➔ `海外已採購` ➔ `國際轉運中` ➔ `已抵台待付尾款` ➔ `已結清待出貨` ➔ `已發貨完成`。
   - 多維度篩選（依客戶、採購國別、訂單狀態、付款狀態、關鍵字快速搜尋）。
   - 訂單明細檢視與包裹追蹤碼填寫。
4. **採購彙總 (Purchasing Aggregation)**
   - 將所有「已付訂」的訂單商品按「國家 / 購買管道 / 商品 SKU / 規格顏色」自動聚合。
   - 買手專用採購清單（採購模式）：一鍵勾選「已購入 / 缺貨 / 需退款 / 採購實付原幣」，支援標註購買憑證與採購單號。
5. **收款對帳 (Reconciliation & Payments)**
   - 專門的對帳工作台，分頁切換「第一階段訂金對帳」與「第二階段尾款對帳」。
   - 核對客戶回填的「匯款銀行」、「末五碼 / 交易序號」、「匯款金額」與上傳的交易明細。
   - 一鍵「核銷入帳」，系統自動變更對應訂單狀態並記帳，支援差額容忍與補款備註。
6. **客戶管理 (CRM)**
   - 客戶名冊、常用超商收件資料（7-11/全家店號或宅配地址）、累計消費金額、歷史委託單、信用評等與 VIP 優惠等級。
7. **系統設定 (Settings & Rates)**
   - 各國幣別即時參考與自訂換算匯率（JPY, KRW, USD, EUR, CNY）。
   - 預設代購手續費率設定（例如基本 8% 或每件最低手續費）。
   - 國際運費費率表（日韓空運 NT$/kg、歐美空運等）。
   - 團隊收款帳號管理（提供給客戶的轉帳銀行、虛擬帳號資訊）。
   - 資料備份與還原（完整 JSON 匯出與匯入）。

#### B. 視覺規範與設計系統
- **調性風格**：專業商用後台 (Clean Professional SaaS)，高信息密度與低視覺疲勞。
- **色彩規劃**：
  - 主畫布背景：灰白沉穩色調 (`#F8FAFC` / Slate 50)，結構邊框以細緻 1px 線條劃分 (`border-slate-200`)。
  - 品牌主色：深靛藍 / 海軍藍 (`#1E293B` / `#0F172A`)，搭配高雅的代購金橙 / 藍調 Accent (`#2563EB` 與 `#F59E0B`)。
  - 語意色彩：綠色（已入帳 / 已採購）、琥珀橙（待核銷 / 待尾款）、天藍（運輸中）、紅色（缺貨 / 逾期款項）。
- **字型與排版**：
  - 數字與金流金額一律套用 `font-mono tabular-nums`，保證金額在表格垂直對齊。
  - 遵循 Zero-Pill 原則，狀態標籤採用低飽和清爽標記，靜態資訊不使用厚重膠囊封裝。

### 3. Key Product Decisions & Trade-Offs

- **決策 1：本地狀態持久化 (IndexedDB + LocalStorage) 搭配資料匯入匯出**
  - *選擇原因*：代購營運後台需具備極速響應、離線可用、資料零洩漏風險，並內建完整種子資料（包含真實代購場景訂單、客戶、跨國幣別），開箱即可直接體驗各項流水線操作。同時提供「一鍵匯出 / 匯入備份」，確保資料安全可攜。
- **決策 2：訂金與尾款二階段獨立收費對帳模型**
  - *選擇原因*：國際代購實務上，空海運費受材積重與實際包材影響，下單時無法精確得知運費；且精品可能產生關稅，因此二階段（訂金先鎖貨，到貨再付運費與尾款）是最符合買手與客戶權益的業界標準流程。
- **決策 3：買手採購聚合模式 (Aggregated Procurement)**
  - *選擇原因*：客戶 A 買 2 件日系衣服，客戶 B 買同款 1 件，買手到專櫃或日本官網下單時需要的是「同品項彙總數量 3 件」，採購彙總頁能直接合併計算，大幅降低買手採購出錯率。

#### 資料模型 (Entities)
- `Order`: 訂單編號、客戶 ID、建立時間、國別、商品列表、狀態 (`draft`, `pending_deposit`, `purchasing`, `shipped_overseas`, `arrived_tw`, `pending_balance`, `fulfilled`, `cancelled`)、第一階段金額、第二階段金額、總毛利、追蹤碼。
- `OrderItem`: 商品名稱、原幣單價、匯率、代購費率、預估重量、購買數量、採購狀態 (`pending`, `purchased`, `out_of_stock`)。
- `PaymentRecord`: 付款階段 (`deposit` / `balance`)、對應訂單編號、金額、匯款銀行、帳號末五碼、付款時間、核銷狀態 (`pending`, `verified`, `rejected`)、審核時間與備註。
- `Customer`: 客戶姓名、LINE/IG 帳號、聯絡電話、收件超商/地址、標籤 (`VIP`, `常客`, `新客`)、累計消費額。
- `ExchangeRateConfig`: 貨幣代碼、當前基準匯率、代購報價匯率、手續費率、每公斤國際運費。
